# NEO-SSH — Claude Context

NEO-SSH consolidates three earlier Rust SSH clients into one code base:

- **ssh4** (`../ssh4`, June 2026) — first egui + crossterm client.
- **ssh4gui** (`../ssh4gui`, July 2026, "SSHGUI") — agent/known_hosts/SFTP/jump/forward work.
- **ssh5** (`../ssh5`) — ssh4gui UI polish plus `ssh5/fresh`, the independent rebuild (v0.1.146).

The code base is `ssh5/fresh`; features unique to ssh4 and ssh4gui were ported on
top. `FEATURES.md` records where every feature came from and which older behaviors
were intentionally not carried over. `docs/REFERENCE.md` is the detailed behavior,
fixture and verification reference; `docs/requirements/` is the product/requirements
packet the rebuild was written against.

## Layout

- `src/lib.rs` — library crate `neo_ssh`: SSH session/connection, terminal engine,
  config, preferences/themes, files (SFTP/SCP/shell backends), forwards, agent,
  trust (known_hosts), ssh_config import, keygen, links, search, row activity.
- `src/main.rs` — binary `neo-ssh`: CLI args, GUI (`desktop.rs`) and CLI
  (`command_line.rs`) front ends, dialogs, file browser, local browser.
- `assets/` + `build.rs` — application icon (generated by `assets/make_icon.py`)
  and Windows exe resources.
- `vendor/` — patched `ssh-rs` 0.5.0, `vt100` 0.15.2 and `egui-winit` 0.28.1
  (see each crate's notes; audit local modifications before replacing them).
- `tests/` — Python/PowerShell acceptance fixtures; `tests/validate.ps1` runs the
  automated gates.

## Definition of done

`cargo fmt --check`, `cargo clippy --all-targets -- -D warnings`, and
`cargo test --all-targets` must pass. `powershell -File tests/validate.ps1`
runs the full gate set (adds SSH fixtures, release build and installer smoke).
Never run fixtures against real hosts without explicit authorization.

## Invariants

- The egui UI thread never blocks on network I/O; sessions run on worker threads
  and talk to the UI through channels.
- Terminal-protocol logic (DA/DSR/CPR/OSC 4/10/11/12 replies, mouse modes,
  bracketed paste, split escape sequences) stays testable without an SSH server.
- Security rules kept from the rebuild: no passwords on the command line; secrets
  are never persisted or logged; host keys are verified and **changed keys are
  rejected**; uploads/downloads never overwrite existing destinations (the only
  exception is the explicit remote **Edit** sync, which replaces the file it
  downloaded after a conflict check); remote folder deletion accepts only empty
  folders; destructive actions are confirmed; debug logging starts off each launch.
- Configuration lives in `~/.neo-ssh.toml`. On first run it is imported read-only
  from `~/.ssh4.toml` (shared by ssh4/ssh4gui/ssh5) with legacy keys translated in
  `Config::migrate_legacy`; unknown keys are preserved so the file stays compatible.
- Windows-first (PowerShell installer), Linux supported, macOS source-compatible.
